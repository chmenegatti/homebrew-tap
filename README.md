# Homebrew tap

Casks for [Zeno](https://github.com/chmenegatti/zeno), a tab-less, local-first API client (REST, GraphQL, gRPC, WebSocket).

```bash
brew install --cask chmenegatti/tap/zeno
```

Zeno is not notarized by Apple yet: on first launch, go to **System Settings › Privacy & Security** and click **Open Anyway**.
